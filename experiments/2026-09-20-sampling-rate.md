# sampling rate จริงของ MAFAULDA คือ 51,200 Hz ไม่ใช่ 50,000 Hz

- วันที่: 2026-09-20
- สคริปต์: `src/data/check_sampling_rate.py`
- ใช้เฉพาะไฟล์ที่ tachometer สะอาด (jitter < 1%): **1718 จาก 1951 ไฟล์**

## ปัญหาที่นำมาสู่การตรวจนี้

หลังเขียน `tachometer.py` เสร็จ เอาความเร็วที่นับได้ไปเทียบกับชื่อไฟล์ พบว่า**ต่ำกว่าอย่างเป็นระบบ 2.33% ทุกไฟล์** ทีแรกสรุปว่าเป็น slip ของมอเตอร์เหนี่ยวนำ

**ข้อสรุปนั้นผิด** เพราะลืมสมมติฐานอีกข้อที่อธิบายลายเซ็นเดียวกันได้

```
ความเร็วที่คำนวณ = fs / จำนวนแถวต่อหนึ่งรอบ
```

ถ้า `fs` ที่ใส่เข้าไปต่ำกว่าความจริง ความเร็วที่ได้ก็ต่ำกว่าความจริงตามสัดส่วนเดียวกันทุกไฟล์ **ซึ่งให้ผลหน้าตาเหมือน slip ทุกประการ**

> **บทเรียน:** ส่วนต่างที่เป็นระบบและคงที่ทุกไฟล์ ชี้ไปที่ค่าคงที่ตัวใดตัวหนึ่งที่เราใส่ผิด ก่อนจะไปอธิบายด้วยปรากฏการณ์ทางฟิสิกส์ ให้ไล่ตรวจค่าคงที่ในสมการก่อนเสมอ

## หลักฐานสนับสนุนจากภายนอกข้อมูล

- **51.2 kHz คือ sampling rate สูงสุดของ NI 9234** ที่ใช้บันทึก ซึ่งระบุไว้ใน รายการอุปกรณ์ของ dataset เอง
- 50,000 / 51,200 = **0.976562** เทียบกับอัตราส่วนที่วัดได้ **1.000089** ต่างกัน 2.353%
- NI 9234 เป็น delta-sigma ADC ที่ความถี่สุ่มมาจากการหารสัญญาณนาฬิกาหลัก ค่าที่ตั้งได้จึงเป็นชุดตายตัว 51.2 kHz คือค่าสูงสุดในชุดนั้น ไม่ใช่ 50 kHz

## ผลที่ตามมา

| สิ่งที่เคยเชื่อ | ค่าที่ถูก |
|---|---|
| fs = 50,000 Hz | **51,200 Hz** |
| ไฟล์ยาว 5.0 วินาที | **4.8828 วินาที** |
| ความละเอียด FFT 0.2000 Hz | **0.2048 Hz** |
| แกนความถี่ของ FFT ถูกต้อง | **คลาดไป 2.4% ต้องสร้างกราฟใหม่ทั้งหมด** |
| ชื่อไฟล์ไม่ใช่ความเร็วจริง | **ชื่อไฟล์ถูกต้อง คลาดเฉลี่ย 0.24%** |
